# Karavan Hold'em

Texas Hold'em (No-Limit) pro partu na mobilech. Jeden telefon založí stůl, ostatní se připojí čtyřpísmenným kódem. Spojení běží peer-to-peer přes PeerJS, není potřeba žádný server ani účet.

Hra: https://janzahradka.github.io/karavan-holdem/

- `index.html` – celá aplikace v jednom souboru (UI, herní engine, knihovna PeerJS 1.5.4).
- Stav hry a zůstatky ukládá telefon hostitele (localStorage).
